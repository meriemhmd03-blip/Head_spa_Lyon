# Site Web – Institut Head Spa

Création complète (conception, développement et déploiement) d'un site web dynamique et responsive pour un institut de bien-être spécialisé dans le Head Spa.

🔗 **Voir le site en ligne :** [monspalyon.fr](https://monspalyon.fr)
---

## Objectifs du projet
* Présenter l'institut, les prestations et les tarifs de manière claire et apaisante.
* Permettre la gestion dynamique des contenus et des demandes de contact/réservation.
* Assurer une navigation fluide sur mobile, tablette et ordinateur.

## Technologies utilisées
* **Front-end :** HTML5, CSS3, Bootstrap, JavaScript
* **Back-end :** PHP, SQL
* **Base de données :** MySQL (requêtes préparées via **PDO**)
* **Hébergement & Déploiement :** o2switch

## Fonctionnalités et bonnes pratiques mises en œuvre
* **Interface Responsive :** Adaptation sur différents formats d'écrans (tests multi-supports et multi-navigateurs).
* **Sécurisation des données :** Protection contre les injections SQL grâce à l'utilisation systématique de **PDO** et validation des formulaires.
* **Architecture claire :** Séparation logique entre l'affichage, le traitement PHP et la connexion à la base de données.

## Ce que ce projet m'a appris
Réalisé de A à Z dans le cadre de ma reconversion (Titre Professionnel Développeur Web et Web Mobile), ce projet m'a permis de confronter mes acquis techniques aux besoins réels d'une cliente, de la maquette jusqu'à la mise en production.
